# 主会话调度契约

目标：一个主会话自动推进三阶段，每阶段默认一个独立工作者持续执行；上下文不足或中断恢复才接替。同一时刻至多一个工作者。

## 派发阶段

1. 初始化/复用 manifest，运行 `pipeline_ctl.py status`，读取 `next_phase`、`next_unit` 和真实缺失项。遵守用户请求的阶段范围。
2. 确认没有同阶段工作者仍在运行。构造任务时指定 `SCOPE=remaining_phase`、`PHASE`、`START_UNIT`、绝对 `SKILL_ROOT`/`VIDEO_WORKSPACE`、该阶段 `PROMPT`、manifest、恢复路径和真实 `FIRST_ERRORS`。**START_UNIT 是起点；工作范围是该阶段全部剩余单元、全片汇总及阶段验收。** 不得加“仅做 Sxxxx”“不得处理其他单元”或固定单元/批次数量上限。
3. 任务要求工作者读取 `agents/WORKER.md`、`references/CONTEXT_CONTINUITY.md` 和该阶段完整 v4 Prompt；主会话自己不载入阶段 Prompt。传递已确认的工具路径、资源约束、实际 `DSH_HOME` 和只读用量命令；明确正常上下文交接需实测 >=90%，没有遥测不能靠估计换人。不能假设全新子智能体看得到父会话历史。
4. 默认一次 `subagent(run_in_background:false)` 执行整个阶段。若 Harness 自动转后台，保存唯一任务 id，按该接口等候；不得并行启动第二位。一次性/可继续模式以实际记录为准，不声称 one-shot 支持 `send_message`。实时通信不是持续处理多个单元的前提。

可直接使用的任务核心：

> 你负责阶段 PHASE 的全部剩余工作，SCOPE=remaining_phase，从 START_UNIT/可信检查点开始。同一上下文逐单元处理、验收、更新语境并继续；六分钟仅为落盘和检查边界。全部单元通过后完成全片一致性、终稿、handoff 和阶段 Gate。只有阶段完成、上下文不足、真实阻塞或用户暂停才返回；不能完成一个单元就退出。正常上下文交接须先用 context_budget.py 验证当前用量达到实际窗口的90%，保存完整交接后才返回 context_handoff；低于阈值、缺少遥测或只是剩余任务很多，都继续下一原子批次。不得执行其他阶段或递归调用子智能体。

## 根据结果继续

- `phase_complete`：实际重跑该阶段 `gate` 和 `status`。通过则启动下一阶段的新工作者；失败不得切阶段。若原工作者可继续，交还具体错误由它修复；若一次性调用已经结束，记录为“阶段验收失败后的恢复”，从磁盘续修，不能标成上下文不足。
- `context_handoff`：先运行 `python3 "<SKILL_ROOT>/scripts/context_budget.py" --dsh-home "<DSH_HOME>" --workspace "<VIDEO_WORKSPACE>" --session-id "<确切子会话ID>"`，独立核实该子级用量与交接文件。只有 `handoff_allowed=true` 才按正常容量交接创建接替者；供应商明确上下文长度拒绝的例外须查看真实错误证据。不能仅采信 observed:true、工作量描述或“剩余上下文不足”的自述。
- 上下文交接证据不足或用量过低：记录 `premature_context_handoff`，不记为正常耗尽。目标仍可继续则让同一子级继续；one-shot 若已经返回，已失去继续原实例的能力，只能保存成果并进行一次异常恢复，在新任务中明确实际窗口、上次用量及 >=90% 门槛。不得把这种恢复当作合理的定期换人，也不能通过停止整个项目惩罚已有实质进展。异常原因、用量与恢复记入现有调度/交接记录；反复无实质进展仍遵循停止规则。
- 合法接替始终负责当前阶段全部剩余工作，交接详细要求见 CONTEXT_CONTINUITY。
- `blocked` / `resource_blocked` / `paused`：保留状态，报告实际原因或暂停，不自动以换人绕过工具、权限或物理内存故障。
- 外部中断：先确认旧任务及重型子进程已结束或可被安全接管，防止重叠运行；从最后可信检查点恢复，保留未完成项。
- 无充分原因只报 `unit_complete` 或单元 JSON 就结束：这是调度契约违例，不能当作预期的逐段轮换。保存已完成成果，核实工具是否强制终止；可继续子级则向同一子级补全范围，不可继续的一次性子级已结束则创建一次恢复工作者并明确整阶段范围。连续两次无实质进展则停止报告。

主会话不执行媒体/语言工作，不复制整个子智能体历史。只接收简短阶段结果与证据路径。已有状态只表明文件进度，不能单凭文件修改时间认定语义审核已推进。用户要求暂停后不再派发新工作者。
